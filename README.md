# Job applicant
Automatically fill job applications by large language model

![](https://shields.io/badge/dependencies-Python_3.14-blue)
![](https://shields.io/badge/dependencies-Google_Chrome_≥_154-orange)



## Install

Create a Python virtual environment and activate.

Run the following command.

```
pip install -r requirements.txt
```

[Paid service] Register and get API key of [Renidly](https://renidly.com/pricing).

You need to have your [LinkedIn](https://www.linkedin.com/) profile.



## Usage

Activate the Python virtual environment.

Run the following command.

```
python app.py
```
